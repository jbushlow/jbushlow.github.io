Research & Projects

Allo-Assisted ASIC Harness (AAAH)

Zhang Research Group · Cornell University

Pushing a design from RTL through ASIC design flows takes a lot of tool time for large designs, even for ones with many repeated subsections for which the tools do a lot of redundant work. Hierarchical flows can remove the redundant work by making reusable macros and stamping them out on the chip, but figuring out which subsections to turn into macros is difficult manual work. I extended Allo to be able to extract this information from its IR, combining it with a full two-stage hierarchical RTL→GDS ASIC flow. The resulting framework reduces tool time by more than 4× and cuts memory usage by 2× for a 16 × 16 systolic array. Slides

Double Duty: FPGA Logic Block Architecture

Abdelfattah Lab · Cornell Tech

FPGA workloads which heavily use adaptive logic module (ALM) adder chains have a tendency to map the lookup tables (LUTs) to wires to get inputs to the chains, meaning that a lot of powerful logic is underutilized. The Double Duty ALM architecture adds extra paths to allow inputs to directly reach the adders while LUTs operate independently and concurrently, at the cost of extra input pins and crossbars. I analyzed input pin utilization and developed architecture variants which share external routing crossbars while still getting the packing density benefits. Paper

Microemboli Detection with Transcranial Doppler

Abdelfattah Lab · Cornell Tech / Weill Cornell Medicine

I helped launch a collaboration with Weill Cornell Medicine to develop an FPGA-based transcranial Doppler (TCD) system for automatically detecting emboli without specialized radiology technicians. While our collaborators work on building the device itself, I developed a signal-processing pipeline for the incoming ultrasound echoes and a simulation framework that models blood flow. The synthetic data gives us a way to test the pipeline before patient data is available and demonstrate that the models we deploy on the FPGA could distinguish simulated emboli from noise. Poster

Spiking Neural Network Tapeout & Parameterized Hardware Generator

ECE 6745 Project · Cornell University

I co-designed a custom (hardware-friendly) leaky integrate-and-fire neuron model and used it to build a programmable accelerator for spiking neural network inference. I also set up a parameterized framework that generates networks, controllers, memory interfaces, and benchmarks for a given topology. To accelerate ASIC design, a hierarchical ASIC flow partitions the design into macros and tiles them on the chip. As an example of how the accelerator can be used, I trained a hardware-aware N-MNIST classifier. I taped out a two-layer, eight-neuron configuration in TSMC's 180 nm process.
